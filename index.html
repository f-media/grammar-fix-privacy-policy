Privacy Policy

Last updated: February 2026

This Privacy Policy describes how the Grammar & Typo Fix Chrome extension (“Extension”) handles information when you use it. The Extension is designed to help correct common typos and grammar as you type.

1. Information stored on your device

The Extension stores the following data locally in your browser (Chrome local storage), on your device only:

  • Your preferences (e.g. whether corrections are enabled, which correction categories are on)
  • Per-site settings, if you change them
  • Optional: Ollama base URL and model name, if you configure AI-based corrections
  • If you enable “Sync preferences with cloud”: a copy of sync-related settings may be cached locally

This data is not transmitted to the developer unless you use optional cloud or remote features described below.

2. Grammar and typo corrections

Built-in rules: Typo and grammar fixes (e.g. “teh” → “the”) can run entirely on your device using built-in rules. No text is sent to any server for this.

Optional Ollama: If you set an Ollama URL and model in the Extension options, the text you type in form fields may be sent to that Ollama instance for grammar correction. That request goes only to the URL you provide (e.g. your local machine or your own server). The Extension developer does not receive this text.

3. Optional cloud and remote features

The Extension may support optional features that communicate with a remote server (for example “Sync preferences with cloud,” or optional writing-assist / address-related features). When you enable such features:

  • Your preferences or sync data may be sent to or fetched from that server.
  • In some configurations, data you enter (e.g. in certain form fields) may be sent to that server. The exact data and server are determined by the configuration (e.g. your organization or the deployment you use).

If you do not enable these optional features, the Extension does not send your typing or form data to any remote server for those purposes.

4. Permissions

The Extension requests storage permission to save your preferences and optional settings, and access to all websites so it can offer corrections on web pages. It does not sell your data to third parties.

5. Changes to this policy

We may update this Privacy Policy from time to time. The “Last updated” date at the top will be revised when we do. Continued use of the Extension after changes means you accept the updated policy.

6. Contact

For questions about this Privacy Policy or the Extension, please use the contact or support option provided in the Chrome Web Store listing or on the developer’s website.
